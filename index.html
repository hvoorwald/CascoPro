Política de Privacidade — CascoPro

Última atualização: 4 de outubro de 2026

O CascoPro respeita a privacidade dos seus usuários. Esta Política de Privacidade explica, de forma simples, como os dados são tratados no aplicativo.

1. Dados armazenados

O CascoPro permite que o usuário registre informações relacionadas aos serviços realizados, propriedades, animais, valores, relatórios e demais informações inseridas pelo próprio usuário.

Esses dados são armazenados localmente no dispositivo do usuário e são utilizados exclusivamente para o funcionamento do aplicativo.

2. Compartilhamento de dados

O CascoPro não vende, aluga ou compartilha os dados pessoais do usuário com terceiros.

Quando o usuário utiliza funções de exportação ou compartilhamento do aplicativo, o envio dos dados ocorre somente por iniciativa do próprio usuário.

3. Coleta automática

O CascoPro não realiza, por conta própria, a coleta de dados pessoais para fins de publicidade ou comercialização.

4. Exclusão dos dados

O usuário pode excluir os dados armazenados pelo aplicativo utilizando as funções de exclusão disponíveis no próprio CascoPro.

A exclusão dos dados não poderá ser desfeita.

5. Segurança

São adotadas medidas técnicas para proteger os dados armazenados pelo aplicativo. Entretanto, nenhum sistema de armazenamento eletrônico pode ser considerado completamente livre de riscos.

6. Alterações nesta política

Esta Política de Privacidade poderá ser atualizada quando necessário. A versão mais recente estará disponível nesta página.
