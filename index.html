Política de Privacidade

Última atualização: 4 de outubro de 2026

1. Dados armazenados

O CascoPro permite registrar informações de serviços, propriedades, animais, valores, relatórios e outras informações inseridas pelo usuário. Esses dados são armazenados localmente no dispositivo e utilizados para o funcionamento do aplicativo.

2. Compartilhamento de dados

O CascoPro não vende, aluga ou compartilha dados pessoais com terceiros. A exportação ou o compartilhamento de informações ocorre somente quando iniciado pelo próprio usuário.

3. Coleta automática

O CascoPro não realiza, por conta própria, coleta de dados pessoais para publicidade ou comercialização.

4. Exclusão dos dados

O usuário pode excluir os dados por meio das funções disponíveis no aplicativo. A exclusão dos dados é irreversível.

5. Segurança

São adotadas medidas técnicas para proteger as informações armazenadas. Entretanto, nenhum sistema eletrônico é completamente livre de riscos.

6. Alterações nesta política

Esta Política de Privacidade poderá ser atualizada quando necessário. A versão mais recente estará disponível nesta página.

Suporte e Guia de Utilização

Veja abaixo como utilizar as principais funções do CascoPro.

1. Cadastre uma propriedade

  1. Acesse CADASTROS → PROPRIEDADE.
  2. Toque em Adicionar.
  3. Preencha as informações.
  4. Toque em Salvar.

A propriedade ficará disponível para ser escolhida nos serviços.

2. Escolha a propriedade

  1. Acesse SERVIÇO.
  2. Entre em PROPRIEDADE.
  3. Toque no campo da propriedade.
  4. Escolha uma propriedade da lista.

3. Preencha os animais

Em SERVIÇO → ANIMAIS, informe os animais e escolha as opções disponíveis nas listas, como espécie, raça e atividades.

Se uma opção ainda não existir, toque em Adicionar, cadastre-a e toque em Salvar.

4. Informe os valores

Acesse SERVIÇO → VALORES e informe os valores do serviço. Confira os valores antes de continuar.

5. Crie o modelo do relatório

  1. Acesse SERVIÇO → RELATÓRIO.
  2. Toque em CRIAR MODELO.
  3. Preencha as informações solicitadas.
  4. Toque em Salvar.

6. Confira o relatório

Em SERVIÇO → RELATÓRIO, toque em VISUALIZAR para conferir a propriedade, data, animais, serviços, valores e demais informações antes de gerar o relatório.

7. Gere o relatório

  1. Confira todas as informações.
  2. Toque em GERAR.

Ao gerar o relatório, o serviço é registrado no banco de dados do aplicativo e passa a ficar disponível no HISTÓRICO.

8. Consulte o HISTÓRICO

Acesse HISTÓRICO para consultar os serviços já gerados. É possível verificar a data, propriedade, quantidade de animais, valores e outras informações.

Também é possível utilizar os filtros para encontrar um serviço com mais facilidade.

9. Consulte ou altere um serviço

Toque em um serviço no HISTÓRICO para acessar suas informações. Você poderá Visualizar/Editar, Carregar as informações para um novo serviço ou Apagar o registro.

Cadastrar → Escolher → Preencher → Conferir → Gerar → Consultar no Histórico
Importante: gerar o relatório é o momento em que o serviço é registrado no banco de dados do aplicativo. Depois disso, ele fica disponível no HISTÓRICO para consulta.
